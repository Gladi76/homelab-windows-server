# Windows Server Homelab

## Overview

This repository documents my personal Windows Server lab environment.

The goal is to gain practical experience in Windows Server administration, Active Directory, network services, virtualization and IT infrastructure management.

## Technologies

- Windows Server 2019 / 2022
- Active Directory Domain Services (AD DS)
- DNS
- DHCP
- Group Policy (GPO)
- Hyper-V
- File Server
- Backup and Recovery
- PowerShell

## Project Goals

- Build and manage a Windows Server infrastructure
- Configure and administer Active Directory
- Implement network services
- Manage users, groups and permissions
- Practice virtualization and server administration
- Document configurations and troubleshooting
