# Hyper-V – Virtual Machine Preparation

## Project Overview

This section documents the preparation of the virtual machine used for the Windows Server 2022 Domain Controller (DC01).

## Virtual Machine

| Configuration | Value |
|---|---|
| VM Name | DC01 |
| Hypervisor | Microsoft Hyper-V |
| Generation | Generation 2 |
| Operating System | Windows Server 2022 Datacenter |
| Role | Domain Controller |

## Hardware Configuration

| Component | Configuration |
|---|---|
| Virtual Processors | 4 vCPUs |
| Assigned Memory | 4096 MB (4 GB RAM) |
| Virtual Hard Disk | 127 GB |
| Virtual Network | To be documented |
